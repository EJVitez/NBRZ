## Artist Bio (copy-paste for all submissions)

NBRZ is an underground music production collective pushing a wide-angle catalog across R&B, urban, cinematic, Latin, and club-ready sounds — all released independently via DistroKid. No genre ceiling, no label filter. Every track is built with intention, from late-night introspective cuts to high-energy floor fillers. The catalog is growing fast and the range is deliberate.

## How To Use This Kit

- **Where to submit:** Use SubmitHub for blog/playlist curators and Groover for European radio and editorial tastemakers. Filter by genre tags that match each bucket below — don't carpet-bomb with the same track across every genre.
- **What to personalize:** Before sending any pitch, check the curator's last 5 features and reference one by name. Swap in a single sentence like "You placed [similar artist] last month — this sits in that same lane." That one line outperforms any amount of extra hype.
- **How to find matching curators:** Search SubmitHub by mood tag (e.g. "late night," "afrobeats adjacent," "cinematic") rather than broad genre. On Groover, filter by playlists that have placed independent artists in the last 60 days — those curators are actively listening, not just collecting submissions.
