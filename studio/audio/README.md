# NBRZ audio for the Forge deck

Drop masters or stems here (MP3 / WAV / OGG / M4A), then point the matching
entry in `../catalog.json` at it:

```json
{ "id": "vertigo", "title": "Vertigo", "file": "audio/vertigo.mp3" }
```

Only add audio NBRZ owns or controls the rights to — anything in this folder is
publicly downloadable once the site is deployed.
